# Model Card

## Identity

Record family, checkpoint filename, SHA-256, training run, package/source revision,
dataset split manifest, seed, hardware, training duration, and final epoch.

## Intended use

Academic comparison and demonstration on five non-person everyday-object classes.
Not for identification, covert surveillance, or safety-critical automation.

## Evaluation

Insert frozen-test precision, recall, F1, mAP@0.5, mAP@0.5:0.95, per-class AP,
confusion matrix, robustness slices, FPS, p50/p95 latency, and checkpoint size.
Link every table or figure to the raw result artifact that generated it.

## Limitations and ethics

Describe false positives, missed small/occluded objects, domain shift, class bias,
privacy constraints, licence obligations, and the hardware dependence of speed.
